# AI 人像姿势与穿搭造型工坊 — 资产分类字典与参数参考

本参考文档定义了 `ai-pose-outfit-studio` 技能内置的四大自有版权视觉参考库分类体系、15 种商业画风预设以及多图参考拼接规则。

## 一、四大视觉参考库（1,902+ 组自有版权高清底图）

1. **3D 动作姿势库 (`pose`，490 组白模 + 490 组 ControlNet Depth 深度图)**
   - **涵盖体系**：
     - `全身单人・标准系`（365 组，覆盖站姿、坐姿、蹲姿、跪立、侧坐、后仰、前倾、扭身、特殊动态）
     - `上半身单人`（125 组，覆盖手部特写、可爱手势、托腮、比心、扶镜框、遮阳等半身构图）
   - **五机位全覆盖**：每个基础动作均配备 `正面`、`斜侧`、`侧面`、`俯视`、`仰视` 5 个标准机位视角，并支持 `--depth` 一键切换 ControlNet Depth 深度图。

2. **四季现实穿搭库 (`costume`，540 套无头人台商城实拍图)**
   - **涵盖分类**：
     - `春季穿搭`（风衣、针织开衫、衬衫百褶裙、西装外套等）
     - `夏季穿搭`（连衣裙、短袖T恤、牛仔短裤、雪纺衫等）
     - `秋季穿搭`（复古毛衣、格纹半身裙、皮夹克、马丁靴等）
     - `冬季穿搭`（毛呢大衣、羽绒服、高领毛衣、长筒靴等）
     - `派对・礼服`（晚礼服、丝绒长裙、宴会高定穿搭）
     - `泳装・度假`（海滩度假风、连体/分体度假泳装）

3. **二次元服装设定集 (`anime`，440 套全分类无头动漫人台立绘)**
   - **涵盖全部 15 大分类**：`制服与校园风`、`春夏休闲`、`秋冬休闲`、`通勤与职场`、`礼服与派对`、`和服`、`泳装`、`运动`、`职业与角色扮演`、`奇幻`、`居家与睡衣`、`节庆与季节`、`偶像与舞台`、`洛丽塔与地雷系`、`军事与科幻`。

4. **沙龙发型正脸模特库 (`portrait`，432 位 85mm 定焦正脸模特)**
   - **涵盖发长**：`短发`、`中发`、`中长发`、`长发`（包含波波头、狼尾剪、公主切、法式大波浪、黑长直、双马尾、丸子头、高马尾、鱼骨辫等数十种细分沙龙造型）。

## 二、15 种画风预设枚举 (`--style`)

| 预设代号 | 风格名称 | 适用场景 |
| :--- | :--- | :--- |
| `realistic` | 写实人像写真 | 85mm 定焦商业人像摄影、自然光街拍 |
| `fashion` | 日韩杂志画报 | 时尚画报、高级感棚拍、穿搭 Lookbook |
| `film` | 复古胶片写真 | 柯达 Portra 400 胶片颗粒、王家卫电影氛围 |
| `ecommerce_adult` | 电商女装模特带货图 | 淘宝/抖音女装全身展示、高转化商品主图 |
| `ecommerce_kid` | 电商童装实拍 | 抖音/小红书童装潮酷街拍与棚拍 |
| `flatlay_to_model` | 平铺衣转真人上身 | 用户上传单件衣服平铺图/挂拍图，自动转为真人模特上身 |
| `anime` | 日系二次元插画 | 精致赛璐珞光影、番剧角色立绘 |
| `cel_anime` | 新海诚感动画电影 | 唯美光影、通透天空与电影感景深 |
| `semi_real` | 2.5D 游戏原画立绘 | 二次元与写实光影融合、高细节织物刻画 |
| `concept_sheet` | 角色设定集立绘 | 纯白背景、全身标准设定集展示 |
| `render3d` | 3D 次世代角色渲染 | Unreal Engine 5 / Octane 渲染质感 |
| `chibi_box` | 3D 潮玩手办质感 | 泡泡玛特风盲盒手办、PVC 哑光涂装 |
| `manga` | 日式黑白漫画网点 | 黑白漫画线稿、精细网点纸与速度线 |
| `cyberpunk` | 赛博朋克霓虹 | 霓虹夜景、冷暖对比光、未来机能风 |
| `none` | 无预设（跟随参考图） | 不强加额外风格词，完全跟随参考图画风 |
